# Public snapshot record

## Baseline

This source preview was prepared on 2026-09-09 from privately maintained Peirce
source at commit `7ef9284fcd9a86adb058f7ae66ec9ceed137a2ae`. The public repository
starts independent history and does not import private commits, branches, tags,
pull requests, discussions, or artifacts. The baseline identifier records
provenance; it is not a promise that private history is publicly accessible.

## Included and adapted

- Project-gateway implementation, schemas, tests, and capability documentation.
- Source principles, usage and self-development skills, and an operator guide.
- Illustrative runtime configuration, empty memory starters, and image recipe
  and offline verification tooling.
- AGPL-3.0-only licensing, contributor credit, citation metadata, and public
  contribution/transparency guidance.

Production source/admin repository IDs and the operational organization were
replaced with unverified examples (`101`, `202`, and `peirce-example`), with
corresponding test changes. Host-specific preserved-state paths were replaced
with examples. Slack is disabled in `config.yaml`. Model/provider labels are
illustrative, not live availability claims. These changes do not make this
snapshot a generic installer or authorize access to those example destinations.

Public-push privacy guidance is stricter than the private baseline: all outgoing
content requires review before public branch pushes, PRs, comments, or uploads.
This is guidance, not a newly implemented host-enforced publication filter.

## Omitted

- Learned user preferences, live memory, and unrelated project references.
- Historical brainstorms, implementation plans, deployment/promotion receipts,
  and the compatibility pointer to those receipts.
- Private deployment procedures, runtime backports, credentials, host state,
  logs, conversations, databases, research materials, and local untracked files.
- Hermes itself, its bundled skills, model weights, and built images.

The remaining technical learning note describes a source-level Git recovery
behavior without importing private project evidence. Image-validator fixtures
are synthetic, including credential-shaped negative-test strings.

## Release boundaries

Source test results and privacy/secret-scan findings are reported with the
release. They do not certify live isolation, provider behavior, model quality,
an image build, or an exact match to production. No live service is changed by
publishing this repository. It is not represented as a complete source offer
for any particular private deployment; see [transparency](transparency.md).

Future updates are deliberate reviewed exports or public contributions, never
automatic synchronization from private source or runtime learning. Each export
needs an exact baseline, reviewed outgoing history/content, compatible rights,
verification, and explicit publication approval. Preserve attribution even
when starting or updating independent public history.
